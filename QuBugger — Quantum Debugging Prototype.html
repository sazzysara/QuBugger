QuBugger

Automated debugging & testing for quantum programs. Bugs in quantum code are silent: the circuit runs, the output looks plausible, and it is wrong. QuBugger tests behaviour from measured output distributions and points at the suspect gate.

Team InnoVentorsLead: Sanjana RQHack India 2026 · Quantum AI with Software

1 · Program under test

Gates: h q · x q · z q · cx c t · cz c t. Edit freely — qubit 0 is the rightmost bit.

Noise: depolarizing-style Pauli errors, 0.2% per 1-qubit gate, 1% per 2-qubit gate. Simulator runs in your browser; fixed seed.

Running…

Assertion testing
Chi-square on measured counts vs expected distribution; shots on impossible outcomes fail the test.
Bug-pattern scan
Linter-style checks, e.g. no entangling gate in a multi-qubit circuit.
Mutation testing
Inject deliberate bugs into the correct circuit; score how many the test catches.
Fault localization
Search single-gate repairs that make the test pass to point at the faulty position.
Scope: browser-side statevector simulator on 2–3 qubit circuits; classical software, no quantum-advantage claim. Not yet run on IBM Quantum hardware or Bugs4Q. Planned: Cirq/OpenQASM input, ML-ranked gate suspiciousness, pytest plugin. The Qiskit/Aer reference prototype is the team's Python implementation; this page re-implements its logic for demonstration.
